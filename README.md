# CMS Hospital Quality and Cost Benchmarking

An evidence-backed portfolio project that combines real CMS hospital quality,
patient-experience, utilization, and Medicare cost-report data into one hospital-level
benchmarking model. The project is under active construction; completed pipeline,
dashboard, Excel report, tests, and source notes are documented in this repository.

> Public CMS data is used for analytical demonstration. Peer flags are screening signals,
> not clinical judgments, rankings of care, or causal estimates.
